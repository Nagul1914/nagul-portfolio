# Nagul Shaik — portfolio

Financial analysis, data science, and a developing focus on applied AI.

**Live site:** https://nagul1914.github.io/nagul-portfolio/

## Files

- `index.html`: profile, experience, expertise, contact, and the existing project sections.
- `design.css`: the editorial layout and responsive profile pages.
- `projects.css`: the original project styles, preserved from the previous version.
- `site.js`: hash navigation, appearance, mobile menu, and project detail controls.
- `assets/Nagul_Shaik_Resume.pdf`: the supplied résumé.

The portfolio is a static site with no build dependencies. GitHub Pages serves the repository root from `main`.

## Preview locally

Run `python -m http.server 8765` in this folder, then open `http://localhost:8765`.

The original `#home`, `#about`, `#skills`, `#da-projects`, `#ba-projects`, `#ib-projects`, and `#contact` URLs remain supported. All 14 project entries retain their original content and links.

The contact links open an email application. No message is sent by the website itself.
